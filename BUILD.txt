================================================================
 D2Trainer Build Guide
================================================================

FOLDER STRUCTURE (after clone)
--------------------------------
  D2Trainer_release\
  |-- disable_dse_v2.cpp       <- DSE patcher source
  |-- gdrv64_bytes.h           <- embedded driver header
  |-- build_dse.bat            <- STEP 1: compiles disable DSE.exe
  |-- build_trainer.bat        <- STEP 2: packs D2Trainer.exe
  |-- BUILD.txt                <- this file
  |
  |-- d2\                      <- launcher payload folder
  |   |-- disable DSE.exe      <- built by build_dse.bat (auto-copied)
  |   |-- Destiny420.ct        <- PUT YOUR CT FILE HERE
  |
  |-- CE-Working\              <- CE payload folder
  |   |-- loader.exe           <- PUT YOUR CE BINARY HERE
  |   |-- d2drv.sys            <- PUT YOUR DRIVER HERE
  |   |-- LnvMSRIO.sys         <- PUT LENOVO DRIVER HERE (Win11 23H2+)
  |   |-- ThrottleStop.sys     <- PUT THROTTLESTOP DRIVER HERE (fallback)
  |
  |-- launcher\                <- launcher source
      |-- launcher.c
      |-- launcher.rc
      |-- launcher.res         <- built by build_trainer.bat

================================================================
 REQUIREMENTS
================================================================
  - Visual Studio 2019/2022/2026 (x64 Native Tools prompt)
    OR MinGW-w64 (g++ in PATH)
  - Windows SDK (included with VS)

================================================================
 BUILD STEPS
================================================================

Open "x64 Native Tools Command Prompt" as Administrator, then:

  Step 1 - Compile DSE patcher:
    build_dse.bat

  Step 2 - Pack D2Trainer.exe:
    build_trainer.bat

Output: D2Trainer.exe  (give this to users)

================================================================
 WHAT D2Trainer.exe DOES WHEN USER RUNS IT
================================================================
  1. UAC prompt (needs admin for driver)
  2. License key dialog
  3. Auth check via systemlocker.net
  4. Extracts files to %TEMP%\d2_XXXXXXXX\
  5. Runs disable DSE.exe -off  (patches g_CiOptions)
  6. Loads d2drv.sys
  7. Runs disable DSE.exe -on   (restores DSE before BattleEye)
  8. Launches CE with Destiny420.ct
  9. On CE close: unloads driver, cleans up

================================================================
 NOTES
================================================================
  - LnvMSRIO.sys / ThrottleStop.sys needed for Win11 23H2/24H2/25H2
  - gdrv.sys is embedded in disable_dse_v2.cpp (no separate file)
  - Users just turn off Real-Time Protection + Core Isolation
  - D2 must NOT be running when launching D2Trainer.exe
